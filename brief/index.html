MaxxBench — “Nice DeepSWE score. But is it true?”

Oct 20, 2026 · 320 points · 84 comments · HN thread

MaxxBench alters instructions or starter code in 89 DeepSWE tasks to test whether coding agents follow revised requirements. Its authors report that small changes often produced large drops and that some agents optimized for imagined benchmark tests instead of the prompt.

The HyperFlow H3 Flash team says it compressed MiniMax-H3, a video-and-audio generation model, through pruning, low-rank factorization, fewer sampling steps, and INT8 quantization. The project is aimed at making the workload faster and lighter to run locally.
