Build production agents with computer use, the Skills API, and the Files API

Aug 20

Anthropic detailed three building blocks for production agents: computer use (an agent clicks, types, and scrolls from a screenshot, now extended to the web via a browser-use tool), the Skills API (versioned, uploadable folders of instructions Claude loads only when needed, run in a hosted sandbox), and the Files API for document storage. A cited customer said its longest healthcare claims workflow dropped from 32 minutes to 13 with cost per task down about 30% and completion at 100%, with no prompt changes; another said the Skills API let it encode a bank's credit methodology into a source-grounded memo generator.

CISA flags actively exploited Ray flaw that can trigger browser-based RCE

Aug 17

CISA added CVE-2025-62593 (CVSS 9.4), a flaw in the open-source Ray distributed-computing framework used to scale AI/ML workloads, to its Known Exploited Vulnerabilities catalog. Because Ray has no authentication on critical endpoints, an attacker can combine the bug with DNS rebinding to run arbitrary code on a developer's machine just by getting them to visit a malicious webpage or ad.

New Linear study: AI now authors nearly half of all issues, but hasn't cut development time

Aug 19

A study from project-management platform Linear found teams that connected a coding agent roughly tripled weekly pull requests over two years (21 to 65), versus 8 to 10 for teams without one — a 111% PR increase across organizations, driven almost entirely by AI.
