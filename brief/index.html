AI made self-hosting fun again

HN thread posted Nov 26, 2026 · 720 points · 355 comments · HN thread

Jan-Lukas Else describes using coding agents against Git-managed Docker Compose files, scripts, and configuration to lower the effort of trying services and automating upkeep. The post credits that reduced friction with making NixOS and a custom bootable server image practical projects again.

AMD-specific fork of llama.cpp

HN thread posted Nov 26, 2026 · 364 points · 87 comments · HN thread

A report on llama-cpp-rdna-boosts recommends its small, AMD-specific patch set over broader inference forks. On the author’s eGPU setup, prefill rose from roughly 700 to 1,300 tokens per second and generation from roughly 35 to 55 tokens per second.

“There have definitely been cases of significant regression of output quality.” — exyi on HN

Kioxia and NVIDIA test SSD-backed expansion of effective GPU memory

Nov 26, 2026

Kioxia and NVIDIA announced a proof of concept using NVIDIA SCADA software and 144 Kioxia NVMe SSDs on a GB200 NVL72 system. The configuration supplies about 1.1 PB of raw flash capacity and is intended to make datasets beyond HBM capacity accessible to GPU processing.

Swarms, Flocks, Gangs: How to build, train, and evaluate multi-agent systems

Nov 26, 2026

Hugging Face published a reproducible TRL walkthrough in which four agents share one small model and communicate on a checkable task. It reports training success rising from 6.6% to 82.3% over 75 updates, while cautioning that communication does not automatically improve on a single agent.

Tencent’s AngelSpec framework documents DFly speculative decoding

Nov 26, 2026

Tencent’s AngelSpec repository is the released training framework behind DFly-style speculative decoders, which combine shared KV context with per-layer fusion. Coverage of the Nov. 26 DFly2 release points to an open release of weights, training code, and a technical report for sparse long-context models.
