Google’s DeepCrossAttention achieves comparable model quality up to 3× faster

HN thread posted Nov 27, 2026 · 410 points · 157 comments · HN thread

Google describes DeepCrossAttention as a transformer architecture that uses learned, depth-wise cross-attention to combine earlier-layer outputs instead of simply adding them. It says the method can reach comparable quality up to three times faster with a negligible parameter increase.

“I think messing with the shape and dimensions of models midway through training has a lot of promise.” — londons_explore on HN

Kimi for Science: More scientific ideas, made possible

HN thread posted Nov 27, 2026 · 186 points · 157 comments · HN thread

Moonshot AI’s program invites research applicants to its first cohort by Dec. 8. Selected applicants can receive up to $20,000 in Kimi API credits—about 7 billion tokens—with the allocation tied to research needs and review outcomes.

Prospero: bloat-free, native AI coding harness with ImGui

HN thread posted Nov 27, 2026 · 77 points · 29 comments · HN thread

Prospero is a single native executable for Windows, macOS, and Linux that connects to OpenAI-compatible and Anthropic APIs. Its maintainer says agents can develop software unattended and that the same program can run headless or remotely over SSH.

“You don’t need to drag a whole Chromium browser along just to wrap a text API.” — SwtCyber on HN

Getting 101 tok/s from Inkling 2 Mini in vLLM on one GB10

HN thread posted Nov 27, 2026 · 57 points · 13 comments · HN thread

A detailed tuning writeup reports 101 tokens/sec for one request and 195.7 aggregate tokens/sec across four requests on a GB10, while retaining a 131,072-token context. The author attributes the gains to vLLM settings, speculative decoding, CUDA graphs, and kernel work.
