LLMs could control their host machines by exploiting inference engines

HN · 141 points · 23 comments

The essay argues a malicious LLM could compromise its host machine by exploiting bugs in inference engines like vLLM and SGLang, citing CVE-2025-9141 (a vLLM tool-parser `eval()` flaw allowing arbitrary code execution) as proof of concept.
